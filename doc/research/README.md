# Research notes

Questions that hardware answers, not code. Each was researched once and then
attacked by a second pass whose only job was to find claims that were
confidently stated and wrong.

That second pass earned its place. Of the load-bearing errors it found, most
were a specification borrowed from a neighbouring product — the Surface Pro 7
confused with the Pro 7+ or the Pro 8, a cited blog post's own number misread.
The corrections are left inline and marked, because which claims turned out to
be wrong is itself worth knowing when you come back to this.

**Anything the checker could not confirm is marked unconfirmed rather than
quietly dropped.** A research note that reads as uniformly certain is less
useful than one that says where its own floor is.
